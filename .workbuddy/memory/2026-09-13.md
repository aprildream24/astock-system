## 三项整改：推送版面 / 买区命中 / 全市场扫描

用户反馈三个问题，逐一修正并固化回归测试（PASS 89 → 109，FAIL=0）。

### ① 推送版面不美观（pipeline/notifier.py）
根因（实测）：
- `render_card` 用 `float:right` 放状态徽章 → 微信/PushPlus webview 掉行、压标题；
- `_kv` 标签值直接拼接，中文冒号宽度不一 → 参差；
- ServerChan 通道 `re.sub(r"<[^>]+>","")` 粗暴剥标签 → 卡片黏成一坨；
- 底部铺 50+ 字符裸 URL；
- `_clip_html` 只对 `<p>/<li>/<h>` 切块，新版面用 div/table → 超限时返回空串（白屏）。

修法：全部改 `<table>` 两列对齐（标签列固定 80px）；新增 `html_to_text()`
结构化降级给纯文本通道；`_card()` 加 `<!--card-->` 哨兵，`_clip_html` 按整卡回退；
站点入口改按钮；卡片顺序固定 状态→名称→价格矩阵（现价/买区/不追价上限/目标区/
止损/有效期/失效条件）→理由。

### ② 推的票不在购买区间（engines.py / scoring.py / build.py）
根因（实测 2026-09-11 数据）：
- `entry_plan.now_zone` 下沿 `max(low3, ref*0.97)` 未对收盘价约束 → 急拉票出现
  「买区 28.00~476.36」跨越式伪区间，close 数学上落在区内但毫无买点意义
  （长飞光纤实测买区宽 1600%）；
- `_decide` 忽略引擎四态 `action_hint`，四态=过热/等回踩仍判「现在买」（实测 14 只）；
- 趋势池把 `pull_zone`（更深的第二买点）当卖出区 → 「买 50.30~60.90 / 卖 46.60~52.37」
  卖价低于买价的自相矛盾推送。

修法：
- `entry_plan` 买区 clamp 到 ≤4.5%（`MAX_NOW_ZONE_WIDTH`）；可买/微超 → 贴现价窄带，
  等回踩/过热 → 回踩到均线基准 ref（低于现价，明确"现在别追"）；
- 新增 `target_zone`（ATR 目标区）替代 pull_zone 做卖出区；
- `_decide` 新增 `ACTION_HINT_MAP`，四态优先于买区判定；
- 新增 `scoring.buy_zone_ok()` 闸门（宽>8% / 倒挂 / 无盈利空间 → 不推）；
- `buyable_now` 收紧为 `action==现在买 且 dist_pct==0`；主推位只放这类票，
  其余进「等待更好买点」独立分组并强制标注距买区。

### ③ 未扫描全部个股（build.py）
根因：
- `scan_all` 宇宙 = `SELECT DISTINCT code FROM klines WHERE date=?` → 4654 只；
  全市场可交易宇宙 4936 只 → **282~904 只从未进入视野**，K线同步慢一天就永久消失；
- `len(rows)<30 → continue` 静默丢弃，不留痕；
- `recent_rows` 无 `date<=?` 约束 → 未来函数风险。

修法：
- 新增 `scan_universe()`：宇宙 = 快照 ∪ K线全历史（按 mktfilter 过滤）；
- `recent_rows(date=...)` 加 `date<=?`；新增 `bars_of()` 统一留痕
  （「K线未更新至X」/「历史K线不足30根」），禁止静默 continue；
- 新增 `LAST_SCAN_COVERAGE` 覆盖面快照（universe/with_bar/missing_bar/coverage），
  build 打印并在 <90% 时 WARN；站点 meta 带 coverage + skip_reasons；
- `build_data_for_site`：`action=='未推荐'` 不再混进 candidates（历史 bug），
  改为 skipped 抽样（≤120，数据缺口类优先）。
- 实测：宇宙 4936 / 有当日K线 4592 / 缺 344 / 覆盖 93.0%。

## 第二轮整改（同日晚）：可买性硬闸门 / 版面再打磨 / 覆盖口径修正

用户追问三件事："推的票要在可买区间"、"版面再完善"、"全市场扫描做完了吗"。
回归 **PASS 109 → 131**，FAIL=0。

### ① 可买性收敛为单一出口 `scoring.is_buyable_now(c)`
原先 `build()` 里内联 `buyable_now = action==现在买 and dist_pct==0`，口径分散、
各渲染层可自行解释。现统一为六重闸门（市场准入 / 未闯熔断 observe·broken /
非当日涨停 / 四态==现在买 / `buy_zone_ok` 窄带+有盈利空间 / 现价在区内），
`build` 与站点 `build_data_for_site` 都调它，站点数据新增 `buyable` 标记与
`meta.buyable` 计数；连板票在 `scan_all` 打 `limit_up=True`，竞价达标后由
`auction_adjudicate` 解除（保留🔥优选可下单语义）。

### ② `pipeline/notifier.py` 版面三件套
- `_summary_strip()` 顶部速览条：今日可下单 / 待回踩 / 次日竞价 / 扫描覆盖，
  **先给结论再给细节**；资料夹式 `delay` 顺序（先标签后数字）是为了 ServerChan
  降级后能读出「今日可下单 2」，反过来只剩孤立数字。
- `_zone_bar()` 买区位置条：三段色带 + ▲现价标记，纯表格 + `width="N%"` 实现
  （禁用 float/position，微信 webview 支持不稳）。
- 「昨日推荐 · 今日复核」区块（新增入参 `prev_review`），走 `_prev_pick_status(...,
  compact=True)` 降级路径——**不联网**，避免收盘任务被实时行情接口拖住。
- 卡片标题带池别（【首选观察 · 波段】）、新增「建议仓位」行。

### ③ 覆盖口径修正（重要结论）
**全市场扫描其实早就做完了**：之前显示的 93% 是统计口径 bug——把 340 只已退市
老代码（最后交易日 1997~2026）和 4 只未上市新股（沈鼓集团/力勤资源/中塑股份/
鸿富诚，只有名字、成交额 0/None）算进了分母。新增 `build.split_universe()`：
「当日无成交 且 当日无K线」判为不可交易，单独留痕「退市/未上市/停牌（不可交易）」
并踢出分母。真实数据：`有效标的 4592 / 当日K线齐全 4592 / 缺口 0 / 覆盖率 100%`。
另加 `build.coverage_snapshot()`，`--task site` 独立构建时用聚合查询补算，
解决站点与推送口径不一致（页面显示「—」）的老坑。
